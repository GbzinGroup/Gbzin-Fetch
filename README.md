# Gbzin Fetch

Downloader de mídia para Windows desenvolvido pela **Gbzin Group**.

O Gbzin Fetch permite baixar vídeos e áudios de fontes públicas, gerenciar downloads, escolher formatos e qualidades e organizar o histórico de arquivos.

## Tecnologias

* Python
* yt-dlp
* FFmpeg
