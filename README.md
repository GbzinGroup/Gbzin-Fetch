# Gbzin-Fetch
Gbzin Fetch é um downloader de mídia para Windows desenvolvido pela Gbzin Group. Permite baixar vídeos e áudios de fontes públicas, gerenciar filas, escolher formatos e qualidades, organizar downloads e manter histórico. Desenvolvido em Python, com suporte a yt-dlp e FFmpeg, oferecendo uma experiência rápida, moderna e prática.
